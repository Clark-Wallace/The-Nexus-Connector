# MeThinks Idea Catalog

A comprehensive collection of project ideas organized by interest, skill level, and category. These are the types of ideas MeThinks generates for users.

---

## How MeThinks Works

```
┌─────────────────────────────────────────┐
│  User Input                             │
│  • Interests (gaming, music, fitness)   │
│  • Skill level (beginner → advanced)    │
│  • Problem to solve (optional)          │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│  MeThinks AI                            │
│  • Matches interests to project types   │
│  • Calibrates difficulty to skill       │
│  • Adds learning objectives             │
│  • Marks best fit as recommended        │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│  3 Project Ideas                        │
│  ⭐ Starter (easiest)                   │
│  ⭐⭐ Intermediate                       │
│  ⭐⭐⭐ Ambitious (stretch goal)         │
└─────────────────────────────────────────┘
```

## Summary

MeThinks generates **personalized, buildable project ideas** by:

1. **Matching interests** to relevant project categories
2. **Calibrating difficulty** to skill level
3. **Incorporating problems** the user wants to solve
4. **Providing learning objectives** for educational value
5. **Marking recommendations** based on best fit

The goal is to get users from "I don't know what to build" to "I'm building THIS" in under 2 minutes.
