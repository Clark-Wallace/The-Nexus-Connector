# Nexus Connector — v0.3.0 Feature Ideas

## Web UI Redesign

### Layout
- Current UI wastes screen space — chat area is too narrow relative to the page
- Full-width layout with sidebar/main split

### Action Ledger (Sidebar)
- Running log of all actions taken during the session
- Shows tool calls, file operations, API calls in real time
- Collapsible entries with timestamps
- Gives the user visibility into what the AI is doing (governance value prop)

### Settings Panel
- Accessible from header/nav
- Lists all configured AI providers with status (connected / needs API key / not configured)
- Shows current default provider

### AI-Guided Provider Setup (Key Feature)
- "Add New AI" button in settings
- Opens a conversational interface:
  - AI asks: "What AI provider do you want to add?"
  - User says: "TogetherAI" (or Mistral, Cohere, etc.)
  - AI looks up the provider, determines the env var name and base URL
  - AI writes the config to .env
  - Provider appears in settings with a field for the user to enter their API key
  - "Saved to .env" confirmation, field clears
- This is the Nexus value prop in action: the tool uses AI to configure AI

### ~~Markdown Rendering~~ ✅ DONE
- marked.js added, AI responses render with formatted code blocks, lists, bold, tables
- Streaming chunks accumulate and re-render progressively

### ~~Provider Switching~~ ✅ DONE (originally unplanned, shipped early)
- Dropdown selector in header replaces static badge
- /providers and /provider/switch API endpoints
- WebSocket auto-reconnects on provider change

### ~~Tool Execution Feedback~~ ✅ DONE (originally unplanned, shipped early)
- Tool calls and results shown as status lines in chat
- Completion summary with file count
