🚀 Quick Start

Step 1: Open a new terminal window

Step 2: Navigate to the examples folder:

cd /Users/clarkwallace/Desktop/Projects\ Main/The-Nexus-Connector/examples

Step 3: Set up your configuration (first time only):

cp .env.example .env
# Edit .env and add your API keys

Step 4: Start the server with your chosen AI provider:

# OpenAI (ChatGPT)
python nexus_websocket_server.py --provider openai --model gpt-4

# Anthropic (Claude)
python nexus_websocket_server.py --provider anthropic --model claude-3-opus-20240229

# Google (Gemini)
python nexus_websocket_server.py --provider google --model gemini-pro

# Local Models (Ollama)
python nexus_websocket_server.py --provider ollama --model llama2

# Multiple Models (OpenRouter)
python nexus_websocket_server.py --provider openrouter --model qwen/qwen3-coder

Step 5: Keep this page open and click "Connect" above to start chatting!
